# Murder Mystery Scenario Workbench（MM-Workbench）

マーダーミステリーなどの非対称情報ゲームの制作・上演を支援するWebアプリ。登場人物、証拠、フェーズ進行を整理し、配布資料の印刷とGMの進行確認に利用する。

## 現在できること

- 複数作品の新規作成・切り替え・複製、ブラウザ内保存、JSON入出力。
- 登場人物・HO（個人ハンドアウト）・証拠・フェーズ進行の手入力による編集。
- 新規作品での情報トランプ（証拠と個別知識の対応表）と、多重ロック条件の○×管理・候補人数集計。
- HO・カード・図・写真・GM進行資料のプレビュー、印刷画面からの印刷・PDF保存。
- 企画概要・HO・台本のテキスト出力、GM進行画面とタイマー。
- 組み込み作品に対応した参加者用の音響操作画面。

対応範囲は画面・作品によって異なる。新規作品は資料画面で本文を編集でき、組み込み作品は閲覧・印刷専用。AIチャットは現在非表示。外部AIへの接続、文章の意味に基づく自動論理検証は未実装。

## 利用前に確認すること

**組み込み作品の原稿・配布資料は画面から編集できない。** AI経由で作品パッケージの原本を更新する。人数構成・調査選択・タイマーなど当日進行の操作は原稿と別に保持する。新規作品は汎用編集画面を使い、組み込み作品の内容で未設定項目を補わない。

組み込み作品の「⑦ 資料ファイル一覧」から、現行資料・原本・比較用保管資料を参照・ダウンロードできる。資料の正本は `assets/scenarios/<作品ID>/`、配信用の `public/scenarios/` は生成物。参加者用の独立画面は選択中の作品と同期しない。

## 文書の更新

実装変更時は、利用手順・制約・データ項目も同じ変更単位で更新する。型の正本は [`src/types/schema.ts`](src/types/schema.ts)。将来構想を現在の機能として記載しない。共通文書には作品固有の本文・人物・トリックを転載しない。

現行機能の記載は2026-11-09時点のソース確認に基づく。確認方法と限界は[判断記録](docs/DECISIONS.md)を参照。
