# Murder Mystery Scenario Workbench (MM-Workbench)

非対称情報型ミステリー（マーダーミステリー）の設計・執筆を支援するAI共創ワークベンチ。

単なる「設定の清書台帳（CMS）」ではなく、**「複雑な情報パズルの構造化」「多重ロックのロジック検証」「キャラクター内面ドラマとハンドアウト（HO）の対話的共創」**を行うための制作支援環境です。

---

## 🎯 コア設計思想

1. **AI Co-Writer（対話型共創）**
   - シナリオの設計思想や前提を共有したAIとチャットで壁打ちを行いながら、キャラクターの動機、葛藤、口調を練り上げます。
2. **情報トランプ（公開証拠 × 個別専門知識）マトリクス**
   - 「全体公開される証拠」と「各PCのHOに記された専門知識・解釈」が交差することで新たな事実が浮かび上がる情報構造を設計・可視化します。
3. **多重ロック整合性検証**
   - 犯人特定に必要な複数の条件（動機、手段、アリバイ、特殊ルール等）が、論理的破綻なく犯人1名に収束するかを判定・管理します。
4. **リソース & フェーズ連動**
   - 限定された手番、特殊リソースの消費、フェーズ進行に応じた情報開示のバランスを管理します。

---

## 🚀 クイックスタート (Docker)

本プロジェクトはホスト環境に Node.js 等をインストールすることなく、**Docker のみで起動可能**です。

### 1. 起動

```bash
docker compose up
```

起動後、ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスしてください。

### 2. コンテナの停止

```bash
docker compose down
```
