# 利用ガイド

確認日: 2026-11-09。現在の画面とソースに基づく手順。未実装機能は[PRODUCT_VISION.md](PRODUCT_VISION.md)を参照。

## 使う人と画面

| 利用者 | 主な作業 | 使う場所 |
|---|---|---|
| 作者 | 作品、人物、証拠、進行の編集、配布物の準備 | ローカルアプリの制作・資料・出力タブ |
| GM | 進行確認、証拠配布の判断、時間管理 | GM進行タブ、印刷したGM資料 |
| 参加者 | 対応作品の音響操作 | GMから案内された参加者専用画面 |

作者・GM画面には真相や個別情報を含む。参加者に見せる資料とGM用資料は、配布前に内容を確認する。

## 1. 作品を選ぶ・作る

起動はAIが担当する。起動後に [http://localhost:3000](http://localhost:3000) を開くと作品管理画面が表示される。後から開く場合は左上のフォルダアイコン（「シナリオ・プロジェクト一覧を開く」）を使う。

新しい作品は「新規作成」で題名、人数、GMの有無、世界観、目指す体験を入力する。人物・証拠・進行のひな型が作られるため、初期文面を作品に合わせて置き換える。既存作品の複製、JSONの読込・書出しも作品管理画面で行う。

組み込み作品は閲覧・印刷専用。作品本文・証拠・資料の変更はAI経由で原本を更新する。編集用の複製は別作品として扱い、元作品を書き換えない。複製先は汎用の資料エディタを使う。

## 2. 人物と証拠を配置する

「② 登場人物…」タブでプロフィール、記憶、内面、HO本文を編集し、証拠の内容・取得者・入手フェーズ・公開区分を決める。

新規作品には、次の設計用画面がある。

- **情報トランプ**: 証拠と人物を結び付け、その人物の知識と導出結論を記入する。
- **多重ロック**: 条件を追加し、人物ごとの○×と反証理由を入力する。全条件に該当する人数を確認する。

「1人に収束」という表示は入力済みの○×の集計結果。証拠本文から犯人を推理した結果ではない。知識を持つ人物が不在でも解けるか、反証が本文で成立するかは作者が別に点検する。組み込みの協力型作品では、この2画面を表示しない。

## 3. 進行と情報開示を決める

「① フェーズ進行 ＆ タイムライン」でフェーズを選び、状況、全体議論、個別行動、開示証拠を整理する。組み込み作品では専用のタイムラインと図を利用する。

作戦海図と監視図を切り替えられる画面では、地図横の「拡大」で大画面表示を開く。作戦海図のプレイヤー表示・GM表示は切り替えるとすぐに反映され、通常表示と拡大表示で選択を引き継ぐ。拡大画面の「画像を別タブで開く」は配布用の静止画像を開く操作で、画面内の表示切り替えや投下操作とは連動しない。「閉じる」またはEscで通常表示へ戻る。通常表示の地図は下端まで表示し、写真と観測所見は画面幅に合わせて横並び・縦並びを切り替える。

新規作品の「リソース／カウントダウン状態」は文章の記入欄。残数の自動計算や消費履歴の記録はない。フェーズを切り替えても、別端末の参加者画面へ自動配信されるわけではない。

## 4. 配布資料を確認して印刷する

新規・編集用作品は「④ デザイン資料作成・編集」で個人HO・証拠資料・画像資料・GM進行資料を作成する。未作成の資料には別作品のサンプルを表示しない。本文を入力して「プレビューに切替」で確認し、「表示資料を印刷・PDF保存」で出力する。画像資料にはPNG・JPEG・WebPを追加できる。

組み込み作品のタブ名は「④ 配布資料・印刷」。人物・証拠画面や企画書・一括台本画面からは「配布資料・印刷画面へ」で移動できる。HOのB5印刷、カード・図・GM資料のA4印刷、対応カードの両面配置など従来の出力を利用できる。本文や資料の追加・変更はできない。

個人向けハンドアウトの一覧は区分に対応する。本紙・特別カードでは人物一覧、指令書では絞り込み後の指令書一覧、アナウンスカードではカード番号・配布タイミング付きの一覧を表示する。指令書・アナウンスカードを選ぶと、右側の該当紙面へ移動して強調表示する。アナウンスカードは本文面へ移動し、両面印刷用の表裏配置は維持する。強調枠は印刷されない。

「⑦ 資料ファイル一覧」には、現行画像・PDF、編集原本と手順、比較用保管PDF、資料目録をすべて掲載する。区分・検索で絞り込み、「プレビュー」「別画面で参照」「ダウンロード」を使う。比較用資料は現行版とは限らない。旧ブラウザ保存データがある場合は、その書き出しボタンも表示する。

参加者向けに公開するファイルは別に絞り込む。作者用の資料一覧を参加者へそのまま共有しない。

## 5. 企画・台本を書き出す

「⑤ 企画書・一括台本」で企画概要を編集し、概要、HO全集、完全台本のコピー・保存・印刷を行う。文章ファイルは共有・確認用、JSONは作品データの退避・読込用として使い分ける。

新規作品の出力は、その作品の人数・GM有無・フェーズ・人物・証拠・GMメモを参照する。組み込み作品の原稿は企画書画面でも編集できない。

## 6. 当日進行する

「③ GM進行」でフェーズ別の状況・証拠・進行メモを確認し、タイマーを操作する。組み込み作品は専用の進行支援、新規作品は汎用のフェーズ進行画面となる。選択中のフェーズ、調査選択、GM側の判断、タイマーは作品ごとにブラウザ内へ保存する。タブ移動・作品切り替え・再読込後も復元する。計測中のタイマーは画面を離れた間も進み、一時停止で止まる。タイムライン側の入力・調査結果も保存対象だが、開いているモーダルや再生途中の音声・演出は復元しない。

「進行をリセット」は選択中の作品のGM進行・フェーズ画面の進行を最初の状態へ戻し、タイマーを停止して0にする。調査選択・分岐・作戦名などの進行入力も初期化する。確認画面の「リセットする」で実行し、「キャンセル」またはEscで取り消せる。作品本文・資料・人数設定と、ほかの作品の進行は保持する。「タイマーをリセット」は時間だけを0に戻す。

前日の調査を変更して翌日以降の選択が無効になる場合、変更前に確認ダイアログを表示する。承認すると無効な選択だけ解除し、キャンセルすると前日・翌日以降とも変更前の状態を保持する。調査選択はGM進行とタイムラインで共通。

参加者用の独立画面は対応する組み込み作品専用。GMから渡されたURLで開き、音量と音の再生を確認する。作者側で選択した作品やフェーズと自動同期しない。アプリ内の音響タブと、独立した参加者画面では参照データが異なる。音声と波形は同じ発音予定表と音声出力の時計を使う。再生中の重複操作は受け付けず、画面を離れると予約済みのパターン再生を中止する。

## 保存とバックアップ

### 新規作品

編集は利用中のブラウザ内へ自動保存する。別のブラウザ、別端末、別の接続先には自動で移らない。ブラウザのデータ削除で失われるため、作業の区切りで作品管理からJSONを書き出す。

保存に失敗した場合は未保存の警告を表示する。「再保存」でやり直すか、画面を閉じる前に作品管理からJSONを書き出す。新規作成・複製・JSON読込は保存成功後に一覧へ追加する。

進行状態は作品本文とは別に保存する。作品JSONには含まれず、複製・別端末への移動では引き継がない。ブラウザのデータ削除でも失われる。

JSONを読み込むと新しいIDの作品として追加される。既存作品の上書き復元ではない。読込直後は現在の画面にデータを渡すため、不足項目の多い旧形式ファイルについては、正常表示や完全な互換性を保証しない。

### 組み込み作品

画面から原稿を保存・削除しない。常にAI経由で更新する作品原本を表示する。以前のブラウザ保存データは一度だけ退避し、「⑦ 資料ファイル一覧」からJSONを書き出せる。これは過去に既に失われた編集を復元する機能ではない。

人数構成、調査選択、当日の判断、タイマーは原稿と別に保存する。
