# Web画面のAI関連文言調査

確認日: 2026-11-09。対象は現在の画面、ページタイトル、関連する旧UIコード。今回の表示変更は、組み込み作品の案内を「組み込み作品は閲覧専用です」にする一箇所。他の文言・機能は調査対象であり、変更していない。

## 現在表示される箇所

| 場所 | 表示 | 実際の処理 | 修正する場合の方針 |
|---|---|---|---|
| 作者・GM画面のブラウザータブ名 | `MM-Workbench \| マーダーミステリーAI共創ワークベンチ` | ページ名にAIを含めているが、Webアプリ内のモデル接続は未実装 | `MM-Workbench \| マーダーミステリー シナリオエディタ` など、現行機能を示す名称にする |
| シナリオ管理 → 新規立ち上げ | 「立ち上げ後、AIチャットで世界観やトリックのアイデアを壁打ちしながら肉付けしていけます。」 | 人数に応じた定型の枠を作成する。チャット画面は表示されず、AIとの対話はできない | 「立ち上げ後、登場人物・証拠・進行を編集できます。」などに変更する |
| 組み込み作品 → 配布資料・印刷 → 個人HOの自己紹介欄 | 「推敲」ボタン | 親画面の非表示プロンプト状態を更新するだけ。回答・推敲結果・原稿反映は発生しない。AIへの接続もない | 現行画面からボタンを外す。機能を実装する場合は提案と反映確認を用意してから表示する |

- ページ名: [`src/app/layout.tsx`](../src/app/layout.tsx)
- 新規作成の案内: [`ProjectManagerModal.tsx`](../src/components/ProjectManagerModal.tsx)
- 推敲ボタン: [`DistributionStudio.tsx`](../src/scenarios/project-deep-sea/DistributionStudio.tsx)

## 非表示の旧コード

| コード | 残っている表現・処理 | 現在の表示状態 |
|---|---|---|
| [`AiChatPanel.tsx`](../src/components/AiChatPanel.tsx) | `AI Co-Writer（共創パートナー）`、`AIに相談・壁打ち...`、演出・論理検証・推敲の役割選択 | ページに描画されない |
| [`src/app/page.tsx`](../src/app/page.tsx) のチャット用状態・送信処理 | 共創の案内、検証・推敲済みとする定型返信 | メッセージを表示するパネルがない。送信処理は600ミリ秒後に定型文を作るもので、モデル推論ではない |
| [`DistributionStudio.tsx`](../src/scenarios/project-deep-sea/DistributionStudio.tsx) のデザイン生成関数 | `Geminiデザインエンジンにより…自動構成しました。` | 結果説明を表示するUIと操作入口がない。処理自体もキーワードの条件分岐による設定選択 |

これらは将来構想や旧実装の残存であり、現在利用できるAI機能として案内しない。ソースコードの変数名・コメントにAIとあるだけの箇所は、画面表示とは区別した。

## 確認方法と範囲

- JSX・文字列・メタデータと、実際に描画される呼び出し経路を照合した。
- localhostの隔離したブラウザーで、変更後の案内、タブ名、新規作成の説明、「推敲」ボタンの表示を確認した。
- 「推敲」を押しても資料領域の表示が変わらず、AIチャットパネルとGeminiの説明が表示されないことを確認した。
- 現行依存関係と通信処理にモデル接続は確認できない。音声合成、定型の枠作成、○×の集計はAI推論とは区別する。
- 利用者の保存データには触れず、他のAI関連文言の変更・旧コード削除は行っていない。
