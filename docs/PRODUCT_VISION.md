# 目指す体験と実装状況

確認日: 2026-11-09。将来の機能を約束するロードマップではなく、判断の基準と現在との差分を示す。

## プロジェクトの目的

作者が作品の体験設計に集中できるよう、情報の分散配置、論理の整合、人物の内面とHOの執筆を支える。完成原稿の保存に加え、AIとの対話から考えを整理し、作品データへ反映できる共創のワークベンチを目指す。

現在は、手入力による制作・資料出力・当日の進行支援が中心。コミット履歴からは、組み込み作品の配布物と上演支援への利用が増えたと解釈できる。ただし、履歴は利用者の操作記録ではなく、この解釈を利用実績の証明とはしない。

## 現在と目標の区別

| 領域 | 現在の実装 | 目指す体験・未実装の範囲 |
|---|---|---|
| 作品管理 | 複数作品、ブラウザ内保存、JSON入出力 | 編集を失わず、作品を持ち運べる制作環境 |
| 人物・HO | プロフィール、記憶、内面、本文の手入力 | 対話を通じた動機・葛藤・口調の具体化と反映 |
| 情報トランプ | 証拠・人物・知識・結論の対応表 | 情報の偏り、不在時の行き詰まり、開示順序の検討支援 |
| 多重ロック | ○×条件の編集と該当人数の集計 | 条件の独立性、反証、本文との矛盾の検証支援 |
| 進行・リソース | フェーズ編集、状態の自由記述、GM画面 | 情報開示と残数・時間制約の連動を検討する支援 |
| 資料 | 編集用作品のHO・証拠・画像・GMメモ編集、組み込み作品の閲覧・印刷、資料一覧と全件ダウンロード | 各作品の内容を一貫して出力できる準備工程 |
| 参加者画面 | 組み込み作品用の独立した音響操作 | 作品ごとに必要な参加者体験を提供する仕組み |
| AI連携 | チャット非表示、定型応答などのコードが残存 | 実際のモデル接続、作品文脈の参照、提案の確認とデータ反映 |

将来のAI連携に使うサービス、APIキーの管理、費用、送信データの範囲は未確定。旧設計のAPI方式や2ペイン構成を、決定済み仕様として引き継がない。

## 作品の形式に応じた支援

犯人特定型と協力型では、必要な設計支援が異なる。情報トランプ、多重ロック、内面ドラマの各項目をすべての作品へ一律に要求しない。目標は作品の体験に応じた機能選択だが、原稿の編集権限は登録された作品ID、専用機能の参照は作品パッケージ指定で区別する。

## 改善の優先観点

1. **編集内容の保持**: 組み込み作品は原稿閲覧専用、編集用作品はブラウザ保存として区別した。対話から編集用作品へ提案を反映する体験は今後の課題。
2. **汎用と専用の分離**: 新規作品の資料エディタと出力を分離した。今後も新しい専用機能を共通の既定値へ混ぜない。
3. **実装に合った表示**: AIや自動検証を示す文言が、実際の処理以上の機能を期待させないようにする。
4. **対話から作品への接続**: 作者が提案を確認し、必要な部分を選んで反映できる流れを作る。

AI連携や自動検証の拡張は未実装。着手順と具体的な仕様は、別途作業として決める。
